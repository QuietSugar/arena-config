# arena-config

在沙箱里安全地操作一台 NAT 后面的目标机：连接、同步代码、跑远端脚本，
同时保证**机密永不进入这个仓库**。

```
沙箱 ──SSH/22──> 中转机（ProxyJump 跳板）──> 目标机 sshd
```

## 它能做什么

- **建立连接**：一份 `secrets.json` 导入即成环境——密钥、ssh 配置、主机指纹校验，
  之后 `ssh <别名>` 直接可用。中转机零部署、零权限要求，流量只穿过不落地。
- **保持可用**：沙箱被平台回收（丢 git 配置、剥执行位、卸软件）后，一条
  `arena bootstrap` 自动修复并自我更新到最新版本。
- **同步代码**：`arena sync` 在沙箱与目标机之间双向同步代码树，
  支持先拉后改、干跑预览、推脚本到远端执行（免嵌套引号地狱）。
- **跑远端脚本**：本地写好脚本，`arena sync run` 推到目标机执行，结束自动清理。
- **守住机密**：三层防线（gitignore → 提交钩子 → 全历史审计）保证真实主机、
  密钥、路径前缀永不进入这个公开仓库；`arena scan` 可随时审计
  工作区、全部历史乃至悬空对象。
- **诊断网络**：`arena probe` 探测出网能力，`arena check` 判定连通性并把
  ssh 的原始报错翻译成"该找谁修、修什么"。

## 形态

单一静态二进制 `arena`（Go，从 GitHub Release 下载，sha256 校验），
模板内嵌其中——**空沙箱里只需要这一个二进制 + 一份 secrets.json**，
无需克隆仓库、无需安装任何运行时依赖。它的主要使用者是 AI agent：
每个命令都有稳定退出码（0 成功 / 1 业务失败 / 2 用法错误）和 `--json` 结构化输出。

## 安全模型

- 公开仓零机密：所有私密值只在运行时以 `secrets.json` 明文交给工具，用完落在
  本机 `~/.arena-secrets/`（权限 600）与 `~/.ssh/`，绝不进 git。
- 主机指纹由 secrets.json 里的主机公钥生成并哈希进 known_hosts，
  `StrictHostKeyChecking yes` 常开；指纹变了宁可停下问人，也不盲连。
- 中转机是 TRANSIT ONLY：只允许流量穿过，不登录、不探测、不排查。
- 万一误提交机密：**视为已泄露**——先轮换密钥与路径前缀，再处理仓库
  （删分支不等于删数据）。

## 依赖与许可

沙箱侧只需：`bash`、`rsync`、`git`、OpenSSH、`curl`（装 arena 用）。arena 本体为静态二进制，无运行时依赖。
目标机与中转机侧零安装。MIT，见 [LICENSE](LICENSE)。
